확인 기준일: `2026-08-12`

입학 시기: `2027년 4월`

대상: 도쿄이과대 공학부 건축학과, 호세이대 디자인공학부 건축학과, 리츠메이칸대 이공학부 건축도시디자인학과

> 이 문서는 실제 지원 작업을 관리하기 위한 실행 체크리스트다. 날짜와 요건은 2027학년도 공식 모집요강을 기준으로 확인했지만, 출원 직전에는 반드시 링크된 원문과 출원 시스템의 안내를 다시 확인한다. 모든 시각은 일본 표준시(Japan Standard Time, JST)이며 한국 표준시(Korea Standard Time, KST)와 같다.

## 1. 출원 전 준비 항목

- [ ] 리츠메이칸 TAO(The Admissions Office) 계정을 만들고 이메일 인증을 끝낸다.
- [ ] 리츠메이칸 제출용 졸업·졸업예정증명서, 전 학년 성적증명서를 스캔한다. 학교 인장 또는 학교 관계자 서명이 보이는지 확인한다.
- [ ] 리츠메이칸 지원이유서(Statement of Purpose)를 본인이 일본어 800자 이내로 작성한다. 생성형 AI(Generative AI)로 작성하면 부정행위가 될 수 있다.
- [ ] 도쿄이과대 UCARO 계정을 만들고, 2025년 1월 이후 TOEFL iBT 또는 TOEIC L&R 성적 제출 방식을 확정한다.
- [ ] 도쿄이과대 TOEFL 응시자라면 기관코드 `0438`로 직송을 요청한다. 국내 TOEIC 응시자라면 공개테스트 스코어 확인 서비스에서 신청코드 `00053401`로 제출한다.
- [ ] 도쿄이과대 우편 원본 세트를 완성한다. 제출 서류는 `2026년 9월 2일` 대학 필착이다.
- [ ] 호세이대 우편 원본과 영어 성적 제출 방식을 준비한다. 해외 발송 서류는 `2026년 9월 11일` 대학 필착이다.
- [ ] 세 학교의 모든 증명서에 적힌 영문 이름이 여권, EJU 수험표, 영어 성적표의 영문 이름과 같은지 대조한다.

## 5. 서류 체크리스트

### 5.1 공통 사전 점검

- [ ] 여권 유효기간과 영문 이름을 확인한다.
- [ ] 영문 이름 표기를 여권·EJU·영어시험·학교 증명서에서 일치시킨다.
- [ ] 졸업 또는 졸업예정증명서와 전 학년 성적증명서를 학교에 여러 부 요청한다.
- [ ] 원본, 인증사본(Certified True Copy), 단순 복사의 차이를 학교별로 구분한다.
- [ ] 일본어·영어가 아닌 증명서는 해당 대학이 인정하는 기관의 번역 인증을 받는다.
- [ ] 최근 3개월 이내 사진의 원본 파일과 인화 사진을 준비한다.
- [ ] 제출 전 모든 서류와 결제·직송·우편 추적 화면을 PDF로 보관한다.
- [ ] 학교별로 파일명과 봉투를 분리하고 다른 대학의 서류가 섞이지 않게 한다.

### 5.2 도쿄이과대

- [ ] 지원자조서(志願者調書) 지정양식 ①~④: A4 단면, 일본어, 검은 볼펜 자필
- [ ] 졸업 또는 졸업예정증명서: 원본, 인증사본 또는 대학 원본증명 사본
- [ ] 전 학년 성적증명서: 원본, 인증사본 또는 대학 원본증명 사본
- [ ] 자격증명서: IB·Abitur 등 출원자격 C 해당자만
- [ ] TOEFL iBT 또는 TOEIC L&R 공개테스트 증빙
  - TOEFL: Test Taker Score Report와 기관코드 `0438` 직송 완료 증빙
  - 일본 국내 TOEIC: QR 코드가 있는 디지털 공식인정증 출력물, 신청코드 `00053401` 제출 증빙, 11자리 온라인 번호 증빙
  - 일본 국외 TOEIC: Official Score Certificate 원본과 응시지 증빙
- [ ] EJU 수험표 또는 성적확인서 출력물: 2025년 11월 또는 2026년 6월 중 선택
- [ ] 여권 인적사항·사진 페이지 사본
- [ ] 출원서류 체크시트 지정양식 ⑤
- [ ] Web 출원에서 출력한 주소 라벨
- [ ] 번역: 일본어·영어 이외의 서류는 출신학교, 대사관 등 공적기관, 일본어학교 또는 번역회사가 증명한 일본어·영어 번역 첨부

공학부 건축학과 EJU: 일본어, 수학 코스2, 물리 필수와 화학·생물 중 1과목. 수학·이과는 일본어 출제 언어로 응시해야 한다. 공식 참고점은 일본어 300/400, 수학 120/200, 이과 130/200이며 출원 자격 컷은 아니다.

### 5.3 호세이대

- [ ] 공식 출원폼 1부와 사진 1매: 4×3cm, 3개월 이내, 뒷면에 학부·학과·이름
- [ ] 결제 후 출력한 입학지원서 1부
- [ ] 고교 졸업 또는 졸업예정증명서 원본 1부
- [ ] 고교 성적증명서 원본 1부
- [ ] 해당자: 일본 교육제도 학교 재학 이력이 있으면 중학교 재적증명서
- [ ] 해당자: 일본 국내 일본어학교·전문학교·대학 재학생은 성적·재적·출석 관련 밀봉 증명서
- [ ] 일본 국내 거주자: 주민표 또는 재류카드 앞·뒷면 사본
- [ ] 일본 국외 거주자: 여권 사진 페이지 사본
- [ ] EJU 수험표 사본 또는 성적확인서: 2025년 6월·11월 또는 2026년 6월 중 한 회
- [ ] 영어 외부시험 증빙: 2024년 10월 1일 이후 응시분
  - TOEFL: 기관코드 `0407` 직송과 Test Taker Score Report 동봉
  - IELTS: 공식 요강의 전자 또는 원본 제출 절차 확인
  - TOEIC: Official Score Certificate 원본
- [ ] 해당자: 대학의 COE 대리신청을 원하면 지정 신청원과 여권 사본을 출원 서류에 동봉
- [ ] 공식 체크리스트와 주소 라벨
- [ ] 번역: 일본어·영어·중국어 이외 서류는 출신 고교, 대사관·공증처 등 공적기관의 일본어·영어 번역 인증 필요. 민간 번역회사와 일본어학교 인증은 불인정

디자인공학부 건축학과 EJU: 일본어 독해·청해·청독해 280점 이상, 일본어 기술 필수, 수학 코스2, 이과 물리 포함 2과목. 영어는 TOEFL·IELTS·TOEIC 중 하나가 필요하며 점수 하한은 별도 표에서 요구하지 않는다.

### 5.4 리츠메이칸대

- [ ] 졸업 또는 졸업예정증명서 스캔: 학교 인장 또는 관계자 서명 확인
- [ ] 전 학년 성적증명서 스캔: 전·편입 학교가 있으면 전체 이력 포함
- [ ] 지원이유서: 본인이 일본어 800자 이내로 TAO에 직접 입력
- [ ] 여권 인적사항·사진 페이지 스캔
- [ ] 최근 3개월 이내 컬러 증명사진: 어깨 위, 무모, 무배경, 무보정
- [ ] EJU 성적확인서·통지서 또는 수험표: 전기는 2025년 11월 또는 2026년 6월
- [ ] 일본 고교 출신자가 조사서를 대신 제출하는 경우에만 미개봉 원본을 출원 기간 안에 간이등기·속달 우편 제출
- [ ] 합격 후 제출할 졸업·성적증명서 원본을 별도 보관

이공학부 EJU: 일본어(기술 포함), 수학 코스2, 이과 물리·화학 두 과목. 전기 출원 기준은 일본어 본점 250/400 이상과 기술 30/50 이상이다. 이공학부는 영어 외부시험 제출 대상이 아니다.

#### 리츠메이칸 지원이유서 객관 요건

- 상세 정리: [리츠메이칸대 지원이유서 공식 작성 요건](./ritsumeikan_statement_of_purpose_requirements.md)
- 작성자: 지원자 본인
- 언어·분량: 일본어 800자 이내
- 제출: TAO의 입력란에 직접 입력
- 포함할 범주: 대학 졸업 후 장래 설계, 대학에서 배운 내용을 장래에 어떻게 활용할지
- 금지: 생성형 AI를 이용한 작성. 위반 시 부정행위로 판단될 수 있다.

## 6. 면접·시험 준비표

| 대학 | 형식 | 공식적으로 확인된 평가·지침 |
|---|---|---|
| 도쿄이과대 | 가쓰시카 캠퍼스 대면 | 공학부 건축학과는 `면접`. 10월 3일 09:40 집합이며 수험표와 사진 있는 신분증을 지참한다. |
| 호세이대 | 온라인 | 1차는 EJU·영어·제출서류 종합평가, 2차는 온라인 면접. 디자인공학부 건축학과의 별도 기초학력 구두시험은 요강에 명시되지 않았다. Web 면접 수험 매뉴얼은 10월 말 공개 예정이다. |
| 리츠메이칸 | 국외 거주 온라인 / 국내 거주 BKC 대면 | EJU와 일본어 개인면접 종합평가. 이공학부는 이공 소양 구두시험을 실시한다. 온라인 면접 지침은 A4 백지와 필기구 준비 등을 명시하며, 안내 메일이 시험 5일 전까지 도착하지 않으면 입학센터에 문의하도록 한다. |

개인별 답변 문안은 이 문서의 범위에 포함하지 않는다. 다만 리츠메이칸은 출원서류를 면접 자료로 사용하므로, 본인이 제출한 지원이유서와 학력 정보를 그대로 설명할 수 있어야 한다.

## 7. 합격 후 공통 체크리스트

- [ ] 합격통지서와 입학 수속 안내를 내려받아 여러 곳에 백업한다.
- [ ] 입학금·등록금 납부 마감, 해외송금 수수료와 반영 시간을 확인한다.
- [ ] 국외 거주자는 COE(Certificate of Eligibility) 대리신청 조건과 제출 기한을 즉시 확인한다.
- [ ] COE 발급 뒤 관할 일본 공관에서 유학 비자를 신청한다.
- [ ] 대학 기숙사 신청 기간을 합격자 포털에서 확인한다. 입학 수속과 별도 마감일 수 있다.
- [ ] 민간 주거를 사용할 경우 입주일, 보증인·보증회사, 초기 비용을 확인한다.
- [ ] 항공권은 비자 발급 가능 시점과 대학 오리엔테이션 일정을 확인한 뒤 확정한다.
- [ ] 입국 후 주민등록, 국민건강보험, 재류카드 주소 신고 등 대학 안내를 따른다.
