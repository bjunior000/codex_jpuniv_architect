# 오사카 공립대학 건축학과 모집요강 번역 정리본

대상 원문:

- `2027년도 사비 외국인 유학생 특별선발 입시요항`
  - https://www.omu.ac.jp/admissions/assets/2027_international_student_pre_guide.pdf
- `2026년도 학생모집요강(사비 외국인 유학생 특별선발)`
  - https://www.omu.ac.jp/admissions/assets/13_international_student2026.pdf

주의:

- 2027 문서는 `일정·과목·배점`을 먼저 공개한 요약형 입시요항이다.
- 출원 세부사항은 아직 2027 상세 모집요강이 나오지 않았기 때문에, 이 문서는 `2027 최신 요항 + 2026 상세 모집요강`을 함께 참고한 번역 정리본이다.
- 기준 지원 단위는 `공학부 건축학과(工学部 建築学科)`다.

## 1. 모집 단위와 인원

- 공학부 건축학과는 사비 외국인 유학생 특별선발 대상이다.
- 모집 인원은 `약간명`이다.

## 2. 2027 최신 일정

- 출원 기간: `2026-12-16 ~ 2026-12-21`
- 선발일: `2027-02-25 ~ 2027-02-26`
- 합격 발표: `2027-03-09`

보조 참고:

- 2026 상세 모집요강에서는 `인터넷 출원 등록 시작`과 `우편 제출 기간`을 별도로 공개했다.
- 따라서 2027도 실제 출원 단계에서는 `상세 모집요강 확인`이 필요하다.

## 3. EJU 요건

공학부 표를 번역하면:

- 일본어: 필요
- 이과: `물리 + 화학`
- 수학: `코스2`
- 종합과목: 필요 없음

2026 상세 모집요강 기준 최소 기준점:

- 일본어: `합계 270점 이상`
- 이과: `120점 이상`
- 수학 코스2: `120점 이상`

## 4. 영어 요건

- 이 전형은 `TOEFL/TOEIC 제출형`으로 보이지 않는다.
- 대신 대학 자체 `개별학력검사` 안에 `외국어(外国語)` 시험이 포함된다.
- 즉, 영어는 외부 공인점수보다 `본교 필기시험` 준비가 핵심이다.

## 5. 선발 방식

2027 입시요항과 2026 상세 모집요강을 합치면:

- `EJU`
- `개별학력검사`
  - `이과`
  - `외국어`
  - `수학`
- `구두시험·면접`
- `출원서류`

2026 상세 모집요강 기준으로는:

- 1일차: `이과 + 외국어 + 수학`
- 2일차: `구두시험·면접`

## 6. 추가 준비 서류

- 공학부는 `사진표(写真票)` 제출이 필요하다.
- 현재 확인 범위에서는 공학부 건축학과에 `지원이유서`나 `포트폴리오`는 직접 보이지 않는다.
- 하지만 `구두시험·면접` 대비는 필수다.

## 7. 한줄 해석

- 오사카 공립대 건축 외국인 입시는 `공학부 건축학과` 직접 지원이 가능하다.
- 구조는 `EJU + 대학 자체 필기시험 + 구두시험·면접`이라서, `영어 외부점수형 학교`와는 성격이 다르다.
