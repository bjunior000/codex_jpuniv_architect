# Tier 3 학교 정리

목적:

- 도쿄 내 건축계열 외국인 유학생 입시 중에서 `면접 과정의 부담이 낮은 후보`를 따로 모은다.
- EJU 점수 부담보다 면접 방식, 대면 이동, 구두시험 성격, 별도 필기·소논문 부담을 우선해서 본다.

이번 선별 기준:

- 도쿄도 내 캠퍼스 또는 도쿄도 내 학부 운영
- 건축학과 또는 건축디자인계열이 있을 것
- EJU 성적 제출이 요구될 것
- 면접이 없으면 최우선
- 면접이 있다면 온라인 면접까지만 우선 후보로 둠
- 서류 제출 외에 소논문, 본교 필기, 실기, 학과별 과제, 긴 지원이유서 같은 별도 준비 부담이 없는 곳을 우선

현재 분류:

| 구분 | 대학 | 기준 모집 단위 | 판단 |
|---|---|---|---|
| 최우선 후보 | 호세이대 | 디자인공학부 건축학과 | 전형 전체가 `서류심사 + 온라인 면접`, EJU 필수 |
| 우선 후보 | 시바우라공업대 | 건축학부 건축학과 | 온라인 Zoom 면접, EJU 기준과 영어 성적은 있으나 대면 구두시험 부담 없음 |
| 조건부 후보 | 무사시노대 | 공학부 건축디자인학과 | 해외출원자는 온라인 면접·구두시험, EJU 필수. 국내 출원은 대면 |

주의:

- `경쟁률이 니혼대보다 낮은가`는 이번 판단에서 제외했다.
- 공학원대, 도쿄도시대, 도쿄전기대, 고쿠시칸대, 도쿄도립대, 쿄리츠여자대, 니혼여자대, 짓센여자대, 쇼와여자대, 문화학원대 등은 건축계열 또는 인접 전공이 있어도 `대면 면접`, `구두시험`, `소논문/작문`, `학과별 과제`, `지원이유서` 중 하나 이상 때문에 우선 후보에서 제외 또는 보류했다.
- 여성대학은 지원자 성별 조건이 맞을 때만 검토 가능하다.
